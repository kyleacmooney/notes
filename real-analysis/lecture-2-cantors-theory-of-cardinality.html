Lecture 2 Cantors Theory Of Cardinality

Foundational framework for comparing the sizes of sets, including infinite sets, using bijective correspondences rather than counting

1. The Central Question

¶ Motivation

When do two sets A and B have the same size? This question becomes especially interesting for infinite sets—do the natural numbers and integers have the same size? What about rationals and reals? The answer depends entirely on what we mean by "size."

:= Same Size (Cantor)
$$\text{Two sets have the \textbf{same size} when their elements can be \textbf{paired off}.}$$
Cantor's key insight: size comparison reduces to finding a perfect matching between elements.

2. Functions

¶ Setup

To make "pairing off" mathematically precise, we use the language of functions.

:= Function
$$\text{If } A, B \text{ are sets, a \textbf{function} } f: A \to B \text{ is a mapping that assigns to each } x \in A \text{ a \textbf{unique} element } f(x) \in B.$$
Each input produces exactly one output—never zero, never multiple.
:= Image of a Subset
$$\text{If } C \subseteq A, \text{ the \textbf{image} of } C \text{ under } f \text{ is:} \quad f(C) = \{y \in B : \exists\, x \in C \text{ s.t. } y = f(x)\} = \{f(x) : x \in C\}$$
The set of all outputs when inputs are restricted to C.
:= Preimage (Inverse Image)
$$\text{If } D \subseteq B, \text{ the \textbf{preimage} of } D \text{ is:} \quad f^{-1}(D) = \{x \in A : f(x) \in D\}$$
The set of all inputs whose outputs land in D. The preimage always exists, even when f has no inverse function.

2.1. Injective, Surjective, and Bijective Functions

:= Injective (One-to-One)
$$f: A \to B \text{ is \textbf{injective} if } f(x_1) = f(x_2) \Rightarrow x_1 = x_2$$
Different inputs always produce different outputs. Contrapositive: x₁ ≠ x₂ ⟹ f(x₁) ≠ f(x₂).
▶ ✦ Understanding the Contrapositive

The contrapositive is a logically equivalent way of stating an implication. For any statement of the form $P \Rightarrow Q$ ("if P then Q"), the contrapositive is $\neg Q \Rightarrow \neg P$ ("if not Q, then not P"). The key insight is that a statement and its contrapositive are always logically equivalent—they're just two different ways of saying the exact same thing.

In the context of injectivity, the original definition says: $$f(x_1) = f(x_2) \Rightarrow x_1 = x_2$$ Here, $P$ is "$f(x_1) = f(x_2)$" and $Q$ is "$x_1 = x_2$". Taking the contrapositive, we negate both parts and flip the direction: $$x_1 \neq x_2 \Rightarrow f(x_1) \neq f(x_2)$$ This says "if two inputs are different, their outputs must be different"—which is often the more intuitive way to think about one-to-one functions!

Why is this useful? Sometimes one form is easier to work with than the other. The contrapositive version directly captures the intuition that an injective function "preserves distinctness"—it never maps two different inputs to the same output. When proving a function is injective, you can use whichever form is more convenient for your proof.

:= Surjective (Onto)
$$f: A \to B \text{ is \textbf{surjective} if } f(A) = B, \text{ i.e., } \forall\, y \in B,\, \exists\, x \in A \text{ s.t. } f(x) = y$$
Every element of the codomain is hit by at least one input.
:= Bijective
$$f: A \to B \text{ is \textbf{bijective} if } f \text{ is both injective and surjective.}$$
A bijection establishes a perfect one-to-one correspondence—this is the precise meaning of "pairing off."

2.2. Composition and Inverse Functions

:= Composition
$$\text{If } f: A \to B \text{ and } g: B \to C, \text{ then } g \circ f: A \to C \text{ is defined by } (g \circ f)(x) = g(f(x)).$$
Apply f first, then g to the result.
:= Inverse Function
$$\text{If } f: A \to B \text{ is \textbf{bijective}, then } f^{-1}: B \to A \text{ is defined by:} \\ \text{For } y \in B, \; f^{-1}(y) \text{ is the unique } x \in A \text{ such that } f(x) = y.$$
The inverse function exists only for bijections. Don't confuse with preimage notation—context distinguishes them.
▶ ✦ Inverse Functions and Bijectivity

The definition you're looking at does not explicitly assert that $f^{-1}$ is bijective—it only defines what $f^{-1}(y)$ means for each $y \in B$. However, the bijectivity of $f^{-1}$ is an immediate consequence of this definition, not something we need to assume separately.

Here's why $f^{-1}: B \to A$ is automatically bijective:

Injective (one-to-one): If $f^{-1}(y_1) = f^{-1}(y_2)$, call this common value $x$. Then by definition, $f(x) = y_1$ and $f(x) = y_2$, so $y_1 = y_2$. Thus $f^{-1}$ is injective.

Surjective (onto): For any $x \in A$, let $y = f(x)$. Since $f$ is a function from $A$ to $B$, we have $y \in B$. By definition of $f^{-1}$, we get $f^{-1}(y) = x$. So every element of $A$ is hit by $f^{-1}$, making it surjective.

So while the definition only tells you how to compute $f^{-1}$, the fact that $f^{-1}$ is also bijective follows as a theorem. In fact, you can show that $(f^{-1})^{-1} = f$, which is a nice symmetry: $f$ and $f^{-1}$ are inverses of each other in both directions.

3. Cardinality

:= Same Cardinality
$$\text{Sets } A \text{ and } B \text{ have the \textbf{same cardinality}, written } |A| = |B|, \text{ if there exists a bijection } f: A \to B.$$
This is Cantor's formal answer to "when do two sets have the same size?"
✎ Cardinality Notation
$$\begin{aligned} |A| = |B| &\quad\Leftrightarrow\quad \exists \text{ bijection } f: A \to B \\ |A| = n &\quad\Leftrightarrow\quad A \text{ is finite with } n \text{ elements } (|A| = |\{1, \ldots, n\}|) \\ |A| \leq |B| &\quad\Leftrightarrow\quad \exists \text{ injection } f: A \to B \\ |A| < |B| &\quad\Leftrightarrow\quad |A| \leq |B| \text{ and } |A| \neq |B| \end{aligned}$$
Read |A| as "the size of A"—not as absolute value (which is meaningless for sets).
★ Cantor–Schröder–Bernstein
$$\text{If } |A| \leq |B| \text{ and } |B| \leq |A|, \text{ then } |A| = |B|.$$
Mutual injections imply a bijection exists. Intuitive for finite sets; the infinite case requires proof.
▶ ✦ Intuition for Finite Sets

For finite sets, the Cantor–Schröder–Bernstein theorem is almost trivially intuitive because we can just count. When we write $|A| \leq |B|$, we're saying "set $A$ has at most as many elements as set $B$." For finite sets, this literally means the number of elements in $A$ is less than or equal to the number in $B$.

So if $|A| \leq |B|$ and $|B| \leq |A|$, we're saying something like "$n \leq m$ and $m \leq n$" where $n$ and $m$ are just ordinary counting numbers. From basic arithmetic, this immediately forces $n = m$, meaning the sets have exactly the same size.

Here's a concrete example: Suppose set $A$ has at most as many elements as set $B$ (so you can match every element of $A$ to a unique element in $B$), and simultaneously $B$ has at most as many elements as $A$. If $A = \{1, 2, 3\}$ and $B = \{a, b, c\}$, both conditions hold, and clearly both sets have exactly 3 elements.

The theorem becomes non-obvious for infinite sets, where counting breaks down. For instance, even though the even numbers seem like "half" of the natural numbers, there's a bijection between them ($n \mapsto 2n$), so they have the same cardinality. The theorem guarantees that if you can inject $A$ into $B$ and inject $B$ into $A$, you can always stitch together a genuine bijection—even when infinity makes this far from obvious!

4. Countable and Uncountable Sets

:= Countably Infinite
$$A \text{ is \textbf{countably infinite} if } |A| = |\mathbb{N}|, \text{ i.e., there exists a bijection } f: A \to \mathbb{N}.$$
You can list all elements as a sequence indexed by natural numbers.
:= Countable
$$A \text{ is \textbf{countable} if } A \text{ is finite or countably infinite.}$$
Either you finish counting, or you can count forever in a systematic way.
:= Uncountable
$$A \text{ is \textbf{uncountable} if } A \text{ is not countable.}$$
No systematic listing can exhaust the set—there are "too many" elements.
★ Even/Odd Naturals Equinumerous with ℕ
$$|\{2n : n \in \mathbb{N}\}| = |\mathbb{N}| \quad \text{and} \quad |\{2n - 1 : n \in \mathbb{N}\}| = |\mathbb{N}|$$
The evens and odds are each as large as all of ℕ—a hallmark of infinite sets.
✎ Feynman's Quip
$$\text{``There are twice as many numbers as numbers.''}$$
Cardinalities of infinite sets don't add like finite quantities—ℕ = evens ∪ odds, yet each part has the same cardinality as the whole.

5. Properties of Cardinality

★ Symmetry
$$|A| = |B| \;\Rightarrow\; |B| = |A|$$
If a bijection A → B exists, so does one B → A (the inverse).
→ Proof of Symmetry
$$\text{If } |A| = |B|, \text{ then } \exists \text{ bijection } f: A \to B. \text{ Its inverse } f^{-1}: B \to A \text{ is also a bijection, so } |B| = |A|. \; \square$$
Exercise: verify that f⁻¹ is indeed bijective.
★ Transitivity
$$|A| = |B| \text{ and } |B| = |C| \;\Rightarrow\; |A| = |C|$$
Cardinality equality is transitive—chain bijections via composition.
→ Transitivity: Setup
$$\text{Let } f: A \to B \text{ and } g: B \to C \text{ be bijections. Define } h = g \circ f: A \to C.$$
The composition of bijections is the natural candidate for A → C.
→ Transitivity: h is Injective
$$\text{Suppose } h(x_1) = h(x_2). \text{ Then } g(f(x_1)) = g(f(x_2)). \\ g \text{ injective } \Rightarrow f(x_1) = f(x_2). \quad f \text{ injective } \Rightarrow x_1 = x_2.$$
Injectivity of g and f propagates through the composition.
→ Transitivity: h is Surjective
$$\text{Let } z \in C. \text{ Since } g \text{ is surjective, } \exists\, y \in B \text{ with } g(y) = z. \\ \text{Since } f \text{ is surjective, } \exists\, x \in A \text{ with } f(x) = y. \\ \text{Thus } h(x) = g(f(x)) = g(y) = z. \; \square$$
Surjectivity of both functions ensures every z ∈ C is reached.
