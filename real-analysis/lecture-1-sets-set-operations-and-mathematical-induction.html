💬 Discussion (6 messages)
Briefly what is the Axiom of choice.

Great question! The Axiom of Choice is one of the most famous (and controversial) axioms in set theory. Informally, it states: given any collection of nonempty sets, you can simultaneously choose one element from each set to form a new set.

More precisely, if you have a family of nonempty sets $\{A_i\}_{i \in I}$ (where $I$ is some index set, possibly infinite), the Axiom of Choice guarantees the existence of a "choice function" $f$ such that $f(i) \in A_i$ for every $i \in I$. This seems obvious for finite collections—you just pick elements one by one. But for infinite collections, especially uncountable ones, there's no recipe for how to make these choices, yet the axiom asserts the choice function exists anyway.

As mentioned in the document's discussion of the Well-Ordering Property, the Axiom of Choice is equivalent to the Well-Ordering Theorem—the claim that every set (including $\mathbb{R}$!) can be well-ordered. This leads to some bizarre non-constructive results: we can prove things exist without being able to explicitly describe them. The Banach-Tarski Paradox, where a ball can be decomposed and reassembled into two identical balls, is a famous consequence. Most mathematicians accept the Axiom of Choice because it's incredibly useful, but it remains philosophically provocative because it allows proving existence without construction.

Very concisely answer this question: what is an index set?

An index set is simply a set whose elements are used as "labels" or "addresses" to identify members of a collection. When we write a family of sets $\{A_i\}_{i \in I}$, the set $I$ is the index set—it tells us which subscripts $i$ are valid.

For example, if $I = \{1, 2, 3\}$, then $\{A_i\}_{i \in I}$ means we have three sets: $A_1$, $A_2$, and $A_3$. But $I$ could also be infinite—like $I = \mathbb{N}$ for a countable collection, or even uncountable like $I = \mathbb{R}$. The index set is just the "catalog" of labels we use to organize and refer to the objects in our collection.

Briefly, what do we mean by constructive vs. non-constructive mathematics?

The distinction between constructive and non-constructive mathematics centers on what it means to prove something "exists."

In constructive mathematics, to prove that an object exists, you must actually build or exhibit it explicitly. For example, when we prove the geometric series formula $1 + c + c^2 + \cdots + c^n = \frac{1 - c^{n+1}}{1 - c}$ by induction in the document, we're being constructive—we can actually compute the sum for any specific $n$ and $c$.

In non-constructive mathematics, we can prove something exists without ever describing what it is or how to find it. The classic example from the document's discussion: the Well-Ordering Theorem (via the Axiom of Choice) proves that $\mathbb{R}$ can be well-ordered, meaning there's some ordering where every nonempty subset has a least element. But we cannot actually describe this ordering—we can't say which real number comes "first." The proof shows existence through logical argument (often contradiction) without providing any construction.

This tension is philosophically significant: non-constructive proofs tell us that something exists, but not what it is. Some mathematicians (called constructivists or intuitionists) reject such proofs entirely, while most accept them as valid but acknowledge their limitations.

1. Sets and Basic Notation

:= Set
$$\text{A } \textit{set} \text{ is a collection of objects called } \textit{elements} \text{ or } \textit{members.}$$
The primitive notion upon which all of analysis is built.
:= Empty Set
$$\text{The } \textit{empty set} \text{ is the set with no elements, denoted } \emptyset.$$
The unique set containing nothing.
¶ Standard Notation

We use the following logical symbols throughout the course: • a ∈ S means "a is an element of S" • a ∉ S means "a is not an element of S" • ∀ means "for all" • ∃ means "there exists" • ⇒ means "implies" • ⇔ means "if and only if" (P ⇔ Q means P ⇒ Q and Q ⇒ P)

1.1. Subsets and Equality

:= Subset
$$A \subset B \iff (a \in A \Rightarrow a \in B)$$
A is a subset of B if every element of A is also in B.
:= Set Equality
$$A = B \iff (A \subset B \text{ and } B \subset A)$$
Two sets are equal iff each is a subset of the other—this is the standard proof strategy for set equality.
:= Proper Subset
$$A \subsetneq B \iff (A \subset B \text{ and } A \neq B)$$
A is contained in B but is not all of B.

1.2. Describing Sets

¶ Set Notation Methods

Sets can be described in two ways: • Listing elements: {1, 2, 3} • Set-builder notation: {x ∈ A : P(x)} or {x : P(x)}, read as "all x (in A) satisfying property P(x)"

:= Fundamental Number Sets
$$\begin{aligned} \mathbb{N} &= \{1, 2, 3, 4, \ldots\} && \text{(natural numbers)} \\ \mathbb{Z} &= \{0, 1, -1, 2, -2, \ldots\} && \text{(integers)} \\ \mathbb{Q} &= \left\{\frac{m}{n} : m, n \in \mathbb{Z}, n \neq 0\right\} && \text{(rationals)} \\ \mathbb{R} &= \mathbb{Q} \cup \{\text{irrationals like } \pi, \sqrt{2}, \ldots\} && \text{(reals)} \end{aligned}$$
Each number system extends the previous to solve equations that had no solutions before.
★ Number Set Inclusions
$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$$
The chain of proper inclusions among the standard number systems.
✎ Historical Motivation
$$\begin{array}{lll} \mathbb{Z} & \text{solves } x + 1 = 0 & \text{(no solution in } \mathbb{N}\text{)} \\ \mathbb{Q} & \text{solves } 2x + 1 = 0 & \text{(no solution in } \mathbb{Z}\text{)} \\ \mathbb{R} & \text{solves } x^2 - 2 = 0 & \text{(no solution in } \mathbb{Q}\text{)} \\ \mathbb{C} & \text{solves } x^2 + 1 = 0 & \text{(no solution in } \mathbb{R}\text{)} \end{array}$$
Each number system was invented to close algebraic gaps in the previous one.

2. Set Operations

:= Union
$$A \cup B = \{x : x \in A \text{ or } x \in B\}$$
Collects all elements from both sets.
:= Intersection
$$A \cap B = \{x : x \in A \text{ and } x \in B\}$$
Keeps only elements common to both sets.
:= Set Difference
$$A \setminus B = \{x \in A : x \notin B\}$$
Elements in A that are not in B.
:= Complement
$$A^C = \{x : x \notin A\}$$
Everything in the ambient universe not in A.
:= Disjoint Sets
$$A \text{ and } B \text{ are } \textit{disjoint} \iff A \cap B = \emptyset$$
Two sets with no elements in common.

3. De Morgan's Laws

★ De Morgan's Laws
$$\text{If } A, B, C \text{ are sets, then:} \\ \begin{aligned} (1) \quad & (B \cup C)^C = B^C \cap C^C \\ (2) \quad & (B \cap C)^C = B^C \cup C^C \\ (3) \quad & A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C) \\ (4) \quad & A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C) \end{aligned}$$
Complements convert unions to intersections and vice versa. (3) and (4) are special cases where the complement is relative to A.
¶ Proof Strategy

To prove two sets are equal, we show each is a subset of the other. This reduces set equality to verifying element membership in both directions.

3.1. Proof of De Morgan's Law (1)

→ Goal
$$\text{WTS: } (B \cup C)^C \subset B^C \cap C^C \text{ and } B^C \cap C^C \subset (B \cup C)^C$$
We prove both subset inclusions to establish equality.
→ Part 1: Forward Inclusion
$$\begin{aligned} \text{Let } x \in (B \cup C)^C &\Rightarrow x \notin B \cup C && \text{(def. of complement)} \\ &\Rightarrow x \notin B \text{ and } x \notin C && \text{(De Morgan for logic)} \\ &\Rightarrow x \in B^C \text{ and } x \in C^C && \text{(def. of complement)} \\ &\Rightarrow x \in B^C \cap C^C && \text{(def. of intersection)} \end{aligned}$$
The key step uses De Morgan's law for propositional logic: ¬(P ∨ Q) ⇔ (¬P ∧ ¬Q).
▶ ✦ De Morgan's Law for Logic

The key step here applies De Morgan's Law from propositional logic to break apart the negation of a disjunction (an "or" statement). In logic, De Morgan's Laws state:

$$\neg(P \lor Q) \equiv \neg P \land \neg Q$$

In plain English: "not (P or Q)" is logically equivalent to "(not P) and (not Q)." Think about it this way—if it's not the case that at least one of P or Q is true, then both P and Q must be false.

In the proof, when we say $x \notin B \cup C$, we're really saying "it is NOT the case that ($x \in B$ OR $x \in C$)." Applying De Morgan's Law, this becomes "($x \notin B$) AND ($x \notin C$)." The union $\cup$ corresponds to logical "or" (an element is in the union if it's in one set or the other), so negating membership in a union naturally splits into negating membership in each individual set, connected by "and."

This is why De Morgan's Laws are so powerful in set theory proofs—they let us translate between the complement of unions/intersections and the intersection/union of complements, bridging logic and set operations.

▶ ✦ From Logic to Set Theory

Exactly right! What you're seeing here is a beautiful example of how set theory is built on top of logic. We're not really "extrapolating" De Morgan's Laws—we're actually deriving the set-theoretic version from the logical version by carefully unpacking definitions.

Here's the key insight: every set operation has a logical counterpart hiding inside it. When we define set membership: $$x \in A \cup B \iff (x \in A) \lor (x \in B)$$ $$x \in A \cap B \iff (x \in A) \land (x \in B)$$ $$x \in A^C \iff \neg(x \in A)$$ The set operations ($\cup$, $\cap$, complement) are really just logical operations ($\lor$, $\land$, $\neg$) in disguise, applied to membership statements.

So this proof is doing something clever: it "drops down" from set language to logic (using definitions), applies the logical De Morgan's Law where we already know it works, then "lifts back up" to set language. This is why you end up with the set-theoretic De Morgan's Law: $(B \cup C)^C = B^C \cap C^C$. You're not assuming it—you're proving it from first principles.

This pattern—reducing set theory to logic, doing the work there, and translating back—is fundamental to rigorous mathematics. It shows that set theory inherits its structure from logic, which is why the two have such elegant parallel laws.

→ Part 2: Reverse Inclusion
$$\begin{aligned} \text{Let } x \in B^C \cap C^C &\Rightarrow x \in B^C \text{ and } x \in C^C && \text{(def. of intersection)} \\ &\Rightarrow x \notin B \text{ and } x \notin C && \text{(def. of complement)} \\ &\Rightarrow x \notin B \cup C && \text{(De Morgan for logic)} \\ &\Rightarrow x \in (B \cup C)^C && \text{(def. of complement)} \end{aligned}$$
The argument reverses exactly, which is not always the case in set proofs.
∴ Conclusion
$$(B \cup C)^C = B^C \cap C^C \quad \square$$
Both inclusions established, so the sets are equal by definition.

4. Mathematical Induction

¶ Motivation

Induction is a proof technique for establishing that a statement P(n) holds for all natural numbers. It relies on the well-ordering property of ℕ.

⊢ Well-Ordering Property of ℕ
$$\text{If } S \subset \mathbb{N} \text{ and } S \neq \emptyset, \text{ then } S \text{ has a } \textit{least element}. \\ \text{i.e., } \exists x \in S \text{ such that } x \leq y \text{ for all } y \in S.$$
Every nonempty subset of ℕ contains a smallest element—a fundamental property we take as given.
▶ ✦ Surprising Consequences of Well-Ordering

Yes, this is absolutely true! The Well-Ordering Property seems almost trivially obvious for $\mathbb{N}$—of course every nonempty set of natural numbers has a smallest element. But when mathematicians generalize this idea, things get philosophically wild.

The Well-Ordering Theorem: Using the Axiom of Choice (a foundational but controversial axiom in set theory), one can prove that every set can be well-ordered—including $\mathbb{R}$, the real numbers. This means there exists some ordering of the reals where every nonempty subset has a least element. The catch? This well-ordering is completely non-constructive. We can prove it exists, but we cannot actually describe or visualize it. You cannot say which real number comes "first" or "second" in this ordering.

Connection to Paradoxes: The Axiom of Choice (which implies well-ordering) leads to results like the Banach-Tarski Paradox: you can decompose a solid ball into finitely many pieces and reassemble them into two balls identical to the original. This isn't a trick—it's a theorem. The "pieces" are so bizarre (non-measurable sets) that they can only exist via the Axiom of Choice.

Why It Matters: The well-ordering of $\mathbb{N}$ is the foundation of mathematical induction and recursive definitions. But its generalization forces us to confront deep questions: What does it mean for something to "exist" in mathematics if we can't construct it? This tension between constructive and non-constructive mathematics remains a live debate in the foundations of math.

★ Principle of Mathematical Induction (Pascal, 1665)
$$\text{Let } P(n) \text{ be a statement depending on } n \in \mathbb{N}. \text{ Assume:} \\ \begin{aligned} (1) &\quad P(1) \text{ is true} && \text{(Base case)} \\ (2) &\quad P(m) \text{ true } \Rightarrow P(m+1) \text{ true} && \text{(Inductive step)} \end{aligned} \\ \text{Then } P(n) \text{ is true for all } n \in \mathbb{N}.$$
The base case starts the chain; the inductive step propagates truth from each n to n+1.

4.1. Proof of Induction Principle

→ Setup
$$\text{Let } S = \{n \in \mathbb{N} : P(n) \text{ is false}\}. \quad \text{WTS: } S = \emptyset.$$
We collect all "bad" natural numbers and show this set must be empty.
→ Contradiction Assumption
$$\text{Suppose } S \neq \emptyset. \text{ By WOP, } S \text{ has a least element } x.$$
Proof by contradiction: assume S is nonempty and derive a false statement.
→ x ≠ 1
$$P(1) \text{ is true (base case)} \Rightarrow 1 \notin S \Rightarrow x \neq 1 \Rightarrow x > 1$$
The least element of S cannot be 1 since P(1) holds.
→ Deriving the Contradiction
$$\begin{aligned} x \text{ is least in } S &\Rightarrow x - 1 \notin S && \text{(since } x - 1 < x\text{)} \\ &\Rightarrow P(x-1) \text{ is true} && \text{(def. of } S\text{)} \\ &\Rightarrow P(x) \text{ is true} && \text{(inductive step)} \\ &\Rightarrow x \notin S && \text{(def. of } S\text{)} \end{aligned}$$
But x was chosen as an element of S, so x ∈ S and x ∉ S simultaneously—contradiction.
∴ Conclusion
$$\therefore S = \emptyset, \text{ so } P(n) \text{ is true for all } n \in \mathbb{N}. \quad \square$$
The contradiction forces S to be empty, meaning P(n) holds universally.

5. Applications of Induction

5.1. Geometric Series Formula

★ Geometric Series
$$\text{For all } c \neq 1 \text{ and } n \in \mathbb{N}: \quad 1 + c + c^2 + \cdots + c^n = \frac{1 - c^{n+1}}{1 - c}$$
The closed form for a finite geometric sum.
→ Base Case (n = 1)
$$1 + c = \frac{1 - c^2}{1 - c} = \frac{(1-c)(1+c)}{1-c} = 1 + c \quad \checkmark$$
Direct verification by factoring the numerator.
→ Inductive Hypothesis
$$\text{Assume for } n = m: \quad 1 + c + \cdots + c^m = \frac{1 - c^{m+1}}{1 - c}$$
This is what we assume to prove the n = m + 1 case.
→ Inductive Step
$$\begin{aligned} 1 + c + \cdots + c^m + c^{m+1} &= \frac{1 - c^{m+1}}{1 - c} + c^{m+1} && \text{(by IH)} \\ &= \frac{1 - c^{m+1} + c^{m+1}(1-c)}{1 - c} \\ &= \frac{1 - c^{m+1} + c^{m+1} - c^{m+2}}{1 - c} \\ &= \frac{1 - c^{m+2}}{1 - c} = \frac{1 - c^{(m+1)+1}}{1 - c} \quad \checkmark \end{aligned}$$
Adding c^{m+1} to both sides and simplifying gives the formula for n = m + 1.
∴ Conclusion
$$\text{By induction, the formula holds for all } n \in \mathbb{N}. \quad \square$$
Both base case and inductive step verified.

5.2. Bernoulli's Inequality

★ Bernoulli's Inequality
$$\text{If } c \geq -1, \text{ then } \forall n \in \mathbb{N}: \quad (1 + c)^n \geq 1 + nc$$
A fundamental inequality relating exponential growth to linear growth.
▶ ✦ Bernoulli's Inequality Explained

Bernoulli's Inequality tells us that exponential growth is always at least as fast as linear growth when we're dealing with expressions of the form $(1 + c)^n$. The left side represents repeated multiplication (exponential), while the right side $1 + nc$ is just a simple linear approximation.

Think of it this way: if you invest money at an interest rate $c$ compounded $n$ times, you'll always earn at least as much as if you just got simple interest $n$ times. For example, with $c = 0.1$ and $n = 3$: $$(1.1)^3 = 1.331 \geq 1 + 3(0.1) = 1.3$$ The exponential version "compounds" and pulls ahead, while the linear version just adds the same amount each time.

The condition $c \geq -1$ is crucial because if $c < -1$, then $(1 + c)$ becomes negative, and raising a negative number to various powers alternates between positive and negative values—breaking the inequality. When $c = -1$, the left side becomes $0^n = 0$ (for $n \geq 1$), which still satisfies $0 \geq 1 + n(-1) = 1 - n$ when $n \geq 1$.

This inequality is surprisingly powerful in analysis and is often used to prove limits, establish bounds, and as a stepping stone to more complex results like the binomial theorem. The intuition is simple: compounding effects accumulate, so the "curved" exponential function always stays above its tangent line approximation at $n = 0$.

▶ ✦ The Binomial Theorem

The Binomial Theorem gives us a complete expansion of $(1 + c)^n$ when $n$ is a positive integer:

$$(1 + c)^n = \sum_{k=0}^{n} \binom{n}{k} c^k = 1 + nc + \frac{n(n-1)}{2}c^2 + \frac{n(n-1)(n-2)}{6}c^3 + \cdots + c^n$$

Notice how Bernoulli's Inequality connects: the right side $1 + nc$ is just the first two terms of this full expansion. When $c \geq 0$, all the remaining terms $\frac{n(n-1)}{2}c^2 + \cdots$ are non-negative, which is exactly why $(1 + c)^n \geq 1 + nc$. Bernoulli is essentially saying "the full sum is at least as big as its first two terms."

The binomial coefficients $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ count the number of ways to choose $k$ items from $n$—these are the famous numbers in Pascal's Triangle. So while Bernoulli gives us a useful bound, the Binomial Theorem gives us the exact answer.

→ Base Case (n = 1)
$$(1 + c)^1 = 1 + 1 \cdot c \quad \checkmark$$
Equality holds in the base case.
→ Inductive Hypothesis
$$\text{Assume for } n = m: \quad (1 + c)^m \geq 1 + mc$$
The inequality we assume holds at step m.
→ Key Observation
$$c \geq -1 \Rightarrow 1 + c \geq 0$$
This ensures multiplying by (1+c) preserves the inequality direction.
→ Inductive Step
$$\begin{aligned} (1 + c)^{m+1} &= (1 + c)(1 + c)^m \\ &\geq (1 + c)(1 + mc) && \text{(by IH, since } 1+c \geq 0\text{)} \\ &= 1 + mc + c + mc^2 \\ &= 1 + (m+1)c + mc^2 \\ &\geq 1 + (m+1)c && \text{(since } mc^2 \geq 0\text{)} \quad \checkmark \end{aligned}$$
The extra mc² term only strengthens the inequality.
∴ Conclusion
$$\text{By induction, Bernoulli's inequality holds for all } n \in \mathbb{N}. \quad \square$$
Both base case and inductive step verified.
