Prompt Caching Break Even

Calculates when prompt caching becomes cost-effective compared to no caching

Pricing Model

:= Cache Write Cost
$$C_{\text{write}} = 1.25 \times C_{\text{input}}$$
First-time caching costs 25% more than normal input tokens
:= Cache Read Cost
$$C_{\text{read}} = 0.10 \times C_{\text{input}}$$
Cache hits cost only 10% of normal price (90% discount)

Break-Even Analysis

¶ Setup

Since writes cost 25% more but reads save 90%, we can calculate how many cache hits are needed to break even compared to re-sending the same content without caching.

= With Caching
$$C_{\text{cached}}(n) = 1.25 + 0.10n$$
Total cost for 1 write plus n reads
= Without Caching
$$C_{\text{uncached}}(n) = 1 + n$$
Total cost paying full price each time
→ Break-Even Condition
$$1.25 + 0.10n < 1 + n$$
Find when caching becomes cheaper
→ Solving
$$0.25 < 0.90n \implies n > 0.28$$
Caching wins after just 1 cache hit
∴ Result
$$\text{Break-even at } n \approx 2 \text{ cache hits}$$
After ~2 reads, caching provides pure savings

Cumulative Comparison

= After 2 Reads
$$\text{Cached: } 1.25 + 0.20 = 1.45x \quad\text{vs}\quad \text{Uncached: } 3.00x$$
Already saving over 50% after just 2 cache hits
