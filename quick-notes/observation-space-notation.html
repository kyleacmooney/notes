Observation Space Notation

Single Observations vs Sequences

An observation is an element of O—a single "atomic" thing the agent perceives at one time step. Think of O like an alphabet, where individual observations are letters and sequences of observations are words.

:= Observation
$$o \in O$$
A single perceived symbol at one time step
:= Observation Sequence
$$(o_1, o_3, o_2) \in O^*$$
A "word" built from the observation alphabet

Cartesian Product Notation

:= O^n Definition
$$O^n = \underbrace{O \times O \times \cdots \times O}_{n \text{ times}}$$
The set of all sequences of exactly n observations

This is Cartesian product—all ordered n-tuples you can form from O.

= Examples by Length
$$\begin{aligned} O^0 &= \{\varepsilon\} & \text{(empty sequence only)} \\ O^1 &= \{(o_1), (o_2), (o_3)\} & \text{(length-1 sequences)} \\ O^2 &= \{(o_1,o_1), (o_1,o_2), \ldots\} & \text{(length-2 sequences)} \end{aligned}$$
If |O| = 3, then |O^n| = 3^n

Kleene Star

:= O* Definition
$$O^* = O^0 \sqcup O^1 \sqcup O^2 \sqcup O^3 \sqcup \cdots = \bigsqcup_{n=0}^{\infty} O^n$$
The set of ALL possible finite histories the agent could have seen

The ⊔ (disjoint union) combines all the O^n sets while keeping track of which "level" each sequence came from. This is standard notation from formal language theory.

Function Space Notation

Here's where the superscript means something completely different! This is function space notation, not Cartesian product.

:= Function Space
$$A^{O^*} = \{ f : O^* \to A \}$$
The set of all functions mapping observation histories to actions

Why use exponential notation? It comes from counting: if both sets were finite, you'd choose one output in A for each input in O*, giving |A|^|O*| total functions.

= Counting Intuition
$$|A^X| = |A|^{|X|}$$
One copy of A for each element of X

Key Distinction

✎ Two Uses of Superscript
$$\begin{aligned} O^n &= \underbrace{O \times O \times \cdots \times O}_{n} & \text{(Cartesian product)} \\ A^X &= \{f : X \to A\} & \text{(function space)} \end{aligned}$$
These are related: a function f: X → A is equivalent to an |X|-tuple from A, so A^X ≅ A^|X|
