Cardinality Set Functions

:= Function Composition
$$(g \circ f)(x) = g(f(x))$$
Composition applies f first, then g to the result.
:= Inverse Function
$$f^{-1} \text{ exists} \iff f \text{ is bijective}$$
Only bijections have true inverse functions.
:= Same Cardinality
$$|A| = |B| \iff \exists \text{ bijection } f: A \to B$$
Two sets have the same size exactly when their elements can be perfectly paired.
:= Finite Cardinality
$$|A| = n \iff \exists \text{ bijection } A \to \{1, 2, \ldots, n\}$$
A set has n elements if it pairs perfectly with the first n natural numbers.
:= Cardinality Inequality
$$|A| \leq |B| \iff \exists \text{ injection } f: A \hookrightarrow B$$
An injection means A's elements can pair with some (not necessarily all) of B's elements.
:= Strict Inequality
$$|A| < |B| \iff |A| \leq |B| \land |A| \neq |B|$$
Strict inequality means injection exists but no bijection does.
★ Cantor-Schröder-Bernstein
$$|A| \leq |B| \land |B| \leq |A| \implies |A| = |B|$$
Two injections in opposite directions guarantee a bijection exists—often easier than constructing one directly.
✎ Notation Ambiguity
$$f^{-1}(D) \text{ (inverse image of set)} \neq f^{-1} \text{ (inverse function)}$$
Inverse image always exists for any function; inverse function requires bijectivity.
