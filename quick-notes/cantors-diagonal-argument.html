Cantors Diagonal Argument

Proves that the real numbers cannot be put into one-to-one correspondence with the natural numbers, establishing that different sizes of infinity exist

→ Step 1: Assume Bijection
$$\text{Assume } f: \mathbb{N} \to (0,1) \text{ is a bijection}$$
Proof by contradiction: suppose we could list all reals in (0,1).
→ Step 2: List Representations
$$f(1) = 0.d_{11}d_{12}d_{13}\ldots, \quad f(2) = 0.d_{21}d_{22}d_{23}\ldots, \quad f(3) = 0.d_{31}d_{32}d_{33}\ldots$$
Each real number has a decimal expansion; we arrange them in a grid indexed by d_{ij}.
→ Step 3: Construct Diagonal
$$x = 0.c_1c_2c_3\ldots \quad \text{where } c_n \neq d_{nn} \text{ for all } n$$
The key insight: build a new number by differing from the n-th number at its n-th digit.
→ Step 4: x Not in List
$$x \neq f(n) \text{ for any } n \in \mathbb{N}$$
By construction, x differs from every listed number in at least one digit position.
→ Step 5: Contradiction
$$x \in (0,1) \text{ but } x \notin \text{range}(f) \Longrightarrow \text{contradiction}$$
We found a real number that f misses, contradicting that f is a bijection.
∴ Conclusion
$$\therefore |\mathbb{R}| > |\mathbb{N}| \quad \text{(the reals are uncountable)}$$
The cardinality of the continuum strictly exceeds that of the natural numbers.
