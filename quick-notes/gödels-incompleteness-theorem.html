Gödels Incompleteness Theorem

Demonstrates that any sufficiently powerful formal system contains true statements that cannot be proven within the system itself.

¶ Setup

We have a formal system (like basic math rules) that can talk about numbers.

:= Formal System T
$$T = \text{a set of axioms and rules for proving things about } \mathbb{N}$$
The formal system we're analyzing for completeness.
¶ The Trick

Gödel found a way to encode statements about the system inside the system using numbers.

:= Gödel Numbering
$$\ulcorner \phi \urcorner = \text{a number that encodes the formula } \phi$$
This self-referential encoding is the key innovation.
▶ ✦ Gödel Numbering Example

Gödel numbering assigns a unique natural number to every symbol, formula, and proof in a formal system. Let me walk through a concrete example.

Step 1: Assign numbers to basic symbols. Suppose we use this encoding: $$0 \mapsto 1, \quad S \mapsto 2, \quad = \mapsto 3, \quad ( \mapsto 4, \quad ) \mapsto 5$$ where $S$ is the successor function (so $S(0) = 1$, $S(S(0)) = 2$, etc.).

Step 2: Encode a formula. Consider the formula $0 = 0$. Its symbols get codes $[1, 3, 1]$. Gödel's clever trick uses prime numbers: take the first $n$ primes and raise each to the power of the corresponding symbol's code: $$\ulcorner 0 = 0 \urcorner = 2^1 \times 3^3 \times 5^1 = 2 \times 27 \times 5 = 270$$

Why this works: By the Fundamental Theorem of Arithmetic, every number has a unique prime factorization. So $270$ uniquely decodes back to $[1, 3, 1]$, which gives us "$0 = 0$". This means we can treat statements about formulas as statements about numbers—the key insight behind Gödel's incompleteness theorems.

¶ The Sneaky Sentence

He constructed a sentence G that says "I cannot be proven."

= Gödel Sentence
$$G \equiv \text{"There is no proof of } G \text{ in } T\text{"}$$
A self-referential statement about its own unprovability.
¶ The Dilemma

We now examine what happens in each case—whether G is provable or its negation is provable.

→ Case 1: G is provable
$$T \vdash G \implies G \text{ is false} \implies T \text{ proves something false} \implies T \text{ is inconsistent}$$
If we can prove G, then T proves a falsehood.
→ Case 2: ¬G is provable
$$T \vdash \neg G \implies G \text{ has a proof} \implies G \text{ is true} \implies T \text{ proves something false}$$
If we can prove ¬G, T is also inconsistent.
¶ The Punchline

Neither G nor ¬G can be proven without breaking the system. This forces a remarkable conclusion.

∴ G is Undecidable
$$G \text{ is true but unprovable}$$
G must be true (it really has no proof) yet cannot be proven.
★ First Incompleteness Theorem
$$\therefore \text{Any consistent system has true statements it cannot prove}$$
The profound limitation on formal systems.
