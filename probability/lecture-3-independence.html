Lecture 3 Independence

Developing the mathematical theory of independence in probability, distinguishing it from related but different concepts like disjointness and conditional independence, with applications to multi-event scenarios and Bayesian reasoning.

1. Review: Conditional Probability Foundations

¶ The Conditional Universe

When we learn that event B has occurred, the sample space effectively becomes B. We must reassign probabilities to outcomes, and outcomes outside B now have zero probability.

:= Conditional Probability
$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$
Interpreted as: of the probability mass in B, what fraction also lies in A? Undefined when P(B) = 0.

1.1. Three Core Tools

★ Multiplication Rule
$$P(A \cap B) = P(A) \cdot P(B \mid A)$$
Finds the probability of multiple events occurring together.
★ Total Probability Theorem
$$P(B) = P(A \cap B) + P(A^C \cap B) = P(A)P(B \mid A) + P(A^C)P(B \mid A^C)$$
Breaks down an event's probability by partitioning on scenarios.
★ Bayes' Rule
$$P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}$$
Relates P(A|B) to P(B|A); enables inference from observations back to causes.

2. Practice: Three Coin Tosses

¶ Setup

Consider tossing a biased coin (probability P of heads) three times. Sample space: {HHH, HHT, HTH, HTT, THH, THT, TTH, TTT}. Tree diagram branch labels represent conditional probabilities, but in this model they all equal P regardless of previous outcomes—a special situation called independence.

2.1. Skill 1: Multiplication Rule

= Finding P(THT)
$$P(THT) = (1-P) \cdot P \cdot (1-P) = P(1-P)^2$$
Multiply conditional probabilities along the path through the tree.

2.2. Skill 2: Total Probability

= Exactly One Head
$$P(\text{one head}) = P(HTT) + P(THT) + P(TTH) = 3P(1-P)^2$$
Sum over the three mutually exclusive ways to get exactly one head.

2.3. Skill 3: Bayes' Rule

→ Inference Problem
$$P(H_1 \mid \text{one head}) = \frac{P(H_1 \cap \text{one head})}{P(\text{one head})} = \frac{P(HTT)}{3P(1-P)^2} = \frac{P(1-P)^2}{3P(1-P)^2} = \frac{1}{3}$$
By symmetry each position is equally likely; formal calculation confirms intuition.

3. The Concept of Independence

¶ Intuition

For the coin example, P(H₂) = P regardless of whether we condition on H₁ or T₁. Independence means: the occurrence of one event does not change your beliefs about the other event.

:= Independence (Conditional Form)
$$P(B \mid A) = P(B)$$
First attempt: learning A occurred doesn't change your probability assessment of B.
:= Independence (Product Form)
$$\text{Events } A \text{ and } B \text{ are \textbf{independent} iff } P(A \cap B) = P(A) \cdot P(B)$$
Preferred definition: works for any events including those with zero probability.
◇ Zero-Probability Events
$$\text{If } P(A) = 0, \text{ then } A \text{ is independent of every event } B$$
Since P(A ∩ B) ≤ P(A) = 0, both sides of the product formula equal zero.
✎ Sources of Independence
$$\text{Independence arises from: (1) physical separation of phenomena, or (2) numerical coincidence}$$
Distinct non-interacting systems are independent; sometimes related events satisfy the equation by accident.

4. Independence vs. Disjointness

¶ A Common Misconception

A frequent error is confusing independence with disjointness. In fact, disjoint events with positive probability are maximally dependent, not independent.

★ Disjoint Events Are Dependent
$$\text{If } A \cap B = \emptyset \text{ and } P(A), P(B) > 0, \text{ then } A \text{ and } B \text{ are \textbf{not} independent}$$
P(A ∩ B) = 0 but P(A)·P(B) > 0, so the product formula fails.
→ Intuition
$$P(B \mid A) = 0 \neq P(B)$$
If A occurred, B certainly did not—this is extreme dependence, maximum information transfer.
✎ Venn Diagrams Cannot Determine Independence
$$\text{Independence requires checking } P(A \cap B) = P(A) \cdot P(B) \text{ numerically}$$
The geometric relationship of sets is insufficient; specific probability values must satisfy the equation.

5. Conditional Independence

:= Conditional Independence
$$A \text{ and } B \text{ are \textbf{conditionally independent given } } C \text{ if } P(A \cap B \mid C) = P(A \mid C) \cdot P(B \mid C)$$
In the world where C occurred, learning about A doesn't change beliefs about B.
★ Independence and Conditional Independence Are Distinct
$$A \perp B \not\Rightarrow A \perp B \mid C \quad \text{and} \quad A \perp B \mid C \not\Rightarrow A \perp B$$
Neither implies the other; conditioning can create or destroy independence.

5.1. Two-Coin Example

¶ Setup

Coin A has P(H) = 0.9, Coin B has P(H) = 0.1. Randomly select one coin, then flip it repeatedly. Within each sub-model (conditioned on which coin), flips are independent. But in the combined model, flips are dependent.

→ Unconditional Probability
$$P(H_{11}) = \frac{1}{2}(0.9) + \frac{1}{2}(0.1) = 0.5$$
By total probability, each flip has 50% chance of heads marginally.
→ After Observing 10 Heads
$$P(H_{11} \mid 10H) \approx 0.9 \neq 0.5 = P(H_{11})$$
Bayesian inference: 10 heads strongly suggests Coin A, making flip 11 likely heads.
✎ Source of Dependence
$$\text{The coin choice is a hidden common cause linking all flips}$$
Conditioning on outcomes provides information about which coin was chosen, affecting predictions.

6. Independence of Multiple Events

:= Mutual Independence
$$\text{Events } A_1, \ldots, A_n \text{ are \textbf{independent} if for every subset } \{i_1, \ldots, i_k\}:\\[6pt] P(A_{i_1} \cap \cdots \cap A_{i_k}) = P(A_{i_1}) \cdots P(A_{i_k})$$
Must check all 2ⁿ - n - 1 subcollections of size ≥ 2.
:= Pairwise Independence
$$\text{Events are \textbf{pairwise independent} if every pair satisfies } P(A_i \cap A_j) = P(A_i)P(A_j)$$
A weaker condition than mutual independence.
★ Pairwise Does Not Imply Mutual Independence
$$\text{Pairwise independence} \not\Rightarrow \text{Mutual independence}$$
Pairs can be independent while the full collection is dependent.

6.1. Counterexample

¶ Setup

Two fair coin flips. Define: A = first toss is heads, B = second toss is heads, C = both tosses give same result (HH or TT). Each has probability 1/2.

→ Pairwise Independence Holds
$$P(A \cap B) = P(A \cap C) = P(B \cap C) = \frac{1}{4} = \frac{1}{2} \cdot \frac{1}{2}$$
Each pair satisfies the product formula.
→ Three-Way Independence Fails
$$P(A \cap B \cap C) = P(HH) = \frac{1}{4} \neq \frac{1}{8} = P(A) \cdot P(B) \cdot P(C)$$
Knowing both A and B determines C with certainty, despite pairwise independence.

7. The King's Sibling Problem

¶ Problem Statement

A royal family has two children. We know there is a king (at least one boy). What is the probability the king's sibling is female? Assume each child is equally likely to be boy or girl, and genders are independent.

→ Naive Answer
$$P(\text{sibling is girl}) = \frac{1}{2} \quad \text{(incorrect reasoning)}$$
Tempting but wrong: treats the sibling as if unaffected by the conditioning.
→ Formal Analysis
$$\Omega = \{BB, BG, GB, GG\} \quad \xrightarrow{\text{given at least one boy}} \quad \{BB, BG, GB\}$$
Conditioning eliminates GG, leaving three equally likely outcomes.
∴ Correct Answer
$$P(\text{sibling is girl} \mid \text{at least one boy}) = \frac{2}{3}$$
Two of three remaining outcomes have a girl.
✎ Hidden Assumptions
$$\text{Different stopping rules yield different answers}$$
If the family stops after getting a boy, or if kings eliminate brothers, P = 1. Careful modeling is essential.

8. Key Takeaways

∴ Summary
$$\begin{aligned} &\text{1. Independence: } P(A \cap B) = P(A) \cdot P(B) \\ &\text{2. Disjoint} \neq \text{Independent (disjoint events are maximally dependent)} \\ &\text{3. Venn diagrams cannot determine independence} \\ &\text{4. Independence} \not\Leftrightarrow \text{Conditional independence} \\ &\text{5. Pairwise independence} \not\Rightarrow \text{Mutual independence} \\ &\text{6. Hidden assumptions can dramatically change answers} \end{aligned}$$
Core concepts from Lecture 3 on independence.
