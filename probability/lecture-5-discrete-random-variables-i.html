Lecture 5 Discrete Random Variables I

Introduction to random variables as functions that assign numerical values to experimental outcomes, covering their probability descriptions (PMFs) and summary statistics (expectation, variance).

1. Random Variables: Definition and Structure

¶ Motivation

Random variables allow us to assign numerical values to experimental outcomes, enabling the full machinery of calculus and algebra to be applied to probability problems. The key conceptual point: a random variable is neither random nor a variable—it is a deterministic function. The randomness comes entirely from the experiment (selecting an outcome ω), not from the function itself.

:= Random Variable
$$X: \Omega \to \mathbb{R}$$
A function assigning a real number to each outcome in the sample space.
✎ Multiple Random Variables
$$\text{Given } X: \Omega \to \mathbb{R}, \text{ any } g: \mathbb{R} \to \mathbb{R} \text{ yields a new RV } Y = g(X)$$
Once ω determines X, it automatically determines any function of X.
:= Discrete vs Continuous
$$\begin{cases} \textbf{Discrete:} & X \text{ takes values in a countable set} \\ \textbf{Continuous:} & X \text{ takes values in a continuous range} \end{cases}$$
Discrete uses sums; continuous uses integrals. Concepts transfer between them.

2. Probability Mass Functions

:= PMF
$$p_X(x) = P(X = x) = P(\{\omega \in \Omega \mid X(\omega) = x\})$$
The PMF gives the probability that X takes each possible value.
⊢ PMF Properties
$$\begin{aligned} &(1) \quad p_X(x) \geq 0 \quad \text{for all } x \\ &(2) \quad \sum_x p_X(x) = 1 \end{aligned}$$
Non-negativity and normalization—these are the only constraints a valid PMF must satisfy.

2.1. The Geometric PMF

¶ Setup

Experiment: Flip a biased coin with P(Heads) = p repeatedly until the first Head appears. Let X be the number of tosses required.

:= Geometric PMF
$$p_X(k) = (1-p)^{k-1} p \quad \text{for } k = 1, 2, 3, \ldots$$
Probabilities form a geometric progression—each successive bar is (1−p) times the previous.

2.2. The Binomial PMF

¶ Setup

Experiment: Toss a coin n times (fixed). Let X be the total number of Heads.

:= Binomial PMF
$$p_X(k) = \binom{n}{k} p^k (1-p)^{n-k} \quad \text{for } k = 0, 1, \ldots, n$$
For large n, this approaches a bell curve shape—a preview of the Central Limit Theorem.

3. Expected Value

:= Expectation
$$E[X] = \sum_x x \cdot p_X(x)$$
Weighted average of values, with probabilities as weights.
¶ Interpretations

Two ways to understand E[X]: (1) Frequency interpretation: the long-run average if the experiment is repeated many times. (2) Physics interpretation: the center of gravity of the PMF viewed as a mass distribution, where bar heights represent masses.

∴ Uniform Distribution Mean
$$X \sim \text{Uniform}\{0, 1, \ldots, n\} \implies E[X] = \frac{n}{2}$$
By symmetry, the center of gravity lies at the midpoint—no calculation needed.

3.1. The Expected Value Rule (LOTUS)

★ Law of the Unconscious Statistician
$$E[g(X)] = \sum_x g(x) \cdot p_X(x)$$
Compute E[g(X)] directly from the PMF of X—no need to derive the PMF of g(X).
✎ Nonlinearity Warning
$$E[g(X)] \neq g(E[X]) \quad \text{in general}$$
The average of squares ≠ the square of the average. Only linear functions commute with expectation.

3.2. Linearity of Expectation

★ Linearity Properties
$$\begin{aligned} E[\alpha] &= \alpha \\ E[\alpha X] &= \alpha E[X] \\ E[X + \beta] &= E[X] + \beta \end{aligned}$$
Constants pass through; scaling and shifting behave as expected.
◇ Combined Linearity
$$E[\alpha X + \beta] = \alpha E[X] + \beta$$
Linear transformations are the unique case where expectations pass through the function.

4. Variance

¶ Motivation

Expectation tells us where the distribution is centered; variance quantifies how spread out it is around that center.

:= Variance
$$\text{Var}(X) = E[(X - \mu)^2] \quad \text{where } \mu = E[X]$$
Average squared distance from the mean. Squaring ensures positivity and penalizes outliers.
= Calculation via PMF
$$\text{Var}(X) = \sum_x (x - \mu)^2 \, p_X(x)$$
Direct application of LOTUS with g(x) = (x − μ)².
★ Shortcut Formula
$$\text{Var}(X) = E[X^2] - (E[X])^2$$
"Expected value of square minus square of expected value"—often easier to compute.

4.1. Properties of Variance

★ Variance Properties
$$\begin{aligned} &(1) \quad \text{Var}(X) \geq 0 \\ &(2) \quad \text{Var}(X + \beta) = \text{Var}(X) \\ &(3) \quad \text{Var}(\alpha X) = \alpha^2 \text{Var}(X) \end{aligned}$$
(1) Sum of squares. (2) Shifting moves the mean too. (3) Deviations scale by α, squared deviations by α².
◇ Combined Transformation
$$\text{Var}(\alpha X + \beta) = \alpha^2 \text{Var}(X)$$
Additive constants vanish; multiplicative constants square.

Key Takeaways

✎ Summary
$$\begin{aligned} &\bullet \text{ Random variables are functions } \Omega \to \mathbb{R}; \text{ randomness is in the experiment} \\ &\bullet \text{ PMFs satisfy } p_X(x) \geq 0 \text{ and } \sum_x p_X(x) = 1 \\ &\bullet \text{ } E[X] \text{ is the center of gravity (weighted average)} \\ &\bullet \text{ LOTUS: } E[g(X)] = \sum_x g(x) p_X(x), \text{ but } E[g(X)] \neq g(E[X]) \\ &\bullet \text{ Linearity: } E[\alpha X + \beta] = \alpha E[X] + \beta \\ &\bullet \text{ Variance: } \text{Var}(\alpha X + \beta) = \alpha^2 \text{Var}(X) \end{aligned}$$
The essential machinery for working with discrete random variables.
